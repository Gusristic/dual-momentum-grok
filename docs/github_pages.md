# GitHub Pages

Sitio en `site/`. Sin Netlify/Supabase/Node.

## Activar

1. **Settings → Pages → Source: GitHub Actions**
2. Actions → **Deploy GitHub Pages** → Run workflow (o push a main)

URL: `https://gusristic.github.io/dual-momentum-grok/`

## Actualizar señal

Editar `site/data.js` tras `python -m dual_momentum.cli universe` y push.
